# 第五幕　晚鐘

二〇二六年十月二十五日凌晨三點，帝國各州的時鐘按規定撥回兩點。這一天有二十五個小時。

沃爾特斯是在電機館五樓的實驗室裡過完這一個小時的。她在校對 CP3 報告的第三稿。第二稿以後，第二節第六款拆下來重寫過一次。`git blame` 裡，那幾行掛在另一個提交底下，標題只有兩個字：照擬。

兩點五十八分，她提交了一次。筆電右上角的時鐘跳回兩點。兩點零三分，她又提交了一次。git 存的是格林威治時間，時區欄從 +0200 改成了 +0100，提交的先後一個也沒有亂。

---

福斯是下午兩點到的。電機館星期日只開到六點，五樓除了她們兩個，只有莫爾那一頭的螢幕還亮著，人不在。

實驗室朝西南，兩點以後陽光刺眼，沃爾特斯先去把百葉窗放下了一半。窗外的軸線兩側，當年留作閱兵看台的空地上，蓋起了玻璃幕牆的辦公樓，頂上的招牌還沒有亮：荷蘭的電器公司，瑞士的銀行，帝國半導體總公司。

「說吧。」

沃爾特斯翻開筆電。「make test，C 測試十六組、交叉比對六萬九千次、性質檢查兩千組，UBSan 無未定義行為；Python 二十二項，一點零四秒，全過。動態指令數，ChaCha20 減少百分之三十三點一，RC5 加密百分之四十二點三，金鑰排程百分之十八點九。靜態程式碼，ChaCha20 縮小百分之二十五。分支數，三個核心都沒有變。」她往下捲，「三份報告，系上預審一次通過兩份；CP3 加了一條註腳以後通過。」

「CP3 第三節第六款？」

「五個為什麼，待組員填寫。」

「第四節？」

「遭遇的問題與解法，待組員填寫。」

「第五節？」

「白話說明，二百字以內，待組員填寫。」

福斯點了點頭。

「禮拜二以前寫。」她說，「寫真的。」

「還有一件。」沃爾特斯把筆電轉過來，「作業規定第五節，個人貢獻聲明。我照各人的提交紀錄和分工整理了一份，請您過目。」

摘要是照作業規定附的範本打的，每一條的格式都一樣。

> **埃克特，約翰內斯。** 測資檢查。十六組測資逐筆以鉛筆核對；手寫函式的動態指令數逐行人工點數（三／八、五、二），與模擬器一致。十月八日討論後，出席次序由第四位調整為第三位。佔比百分之十五。
>
> **諾伊曼，費利克斯。** C 參考實作與測試程式、RV32IM 實作、模擬器、量測腳本、效能驗證（使用境外工具 Claude Code，見各報告第六節）。十月二十三日依審讀意見修改 CP3 第二節第六款，已會簽。佔比百分之四十。
>
> **福斯，卡塔琳娜。** 組長。統籌分工，審查並合併 PR，打 `cp1-submit`、`cp2-submit` tag。佔比百分之三十。
>
> **沃爾特斯，莉娜。** 報告校對、會議紀錄。佔比百分之十五。

表格最下方另起一行：

> **CP1、CP2 第六節「本組修改之處」：暫未修改內容。**

福斯看了一會兒最後六個字，用筆把它們劃去，在旁邊寫：CP1 第 2.3 節，交叉比對次數 64,000 改為 69,000（以程式輸出為準）。

「這一行是誰打的？」

「Claude Code 的初稿就這樣寫。我沒動。」

「不用重打。」福斯說，「改過的這份歸檔。」

---

三點十分，莫爾的訊息到了。

教師把本組的 CP1 報告選作下一屆的範例報告，範例頁的按語由助教代擬。題記擬用福斯同學十月八日的一句話：剛好算對，不等於算對。

訊息後面附了一段說明：按 `references/README.md` 的規定，引文須註明來源。經查 `report/紀要/2026-10-08.md` 定稿，未見此句。擬註「據與會同學回憶」，當否，請示。

訊息另附了一張截圖，是 `git log -p` 的輸出，紀要的第二個提交。畫面中段有一行字是紅色的，開頭兩個減號。前一個是 git 加的，表示這一行在這個提交裡刪掉了；後一個是清單的記號。那半行字前後，還各夾著兩個波浪號。

```diff
-- 組長：~~剛好算對，不等~~
```

沃爾特斯站在桌邊等著。

她的祖父在總理府做了十三年記錄，退休的時候坐的還是牆邊那張小桌子。他過世以後，家裡留下一本速記本的影印件，她小時候翻過。第四十一頁中段，有半行字被一道橫線劃掉了，劃得不重，還認得出來。

福斯看完訊息，在範例頁的草稿上寫：出處：二〇二六年十月，電機館三一四小組討論室內部講話。又在莫爾的訊息底下回了一行字。

回覆是：請據原件補錄。

「原件只有半行。」沃爾特斯說。

「半行也是原件。」

六點整，人民大廳的鐘樓報時，電機館按星期日的作息表關門。時鐘撥回以後的第一個傍晚，天黑得早，五點不到，軸線兩側的路燈就亮了。

---

紀要的補錄，是當天下午三點三十四分在沃爾特斯的筆電上提交的，離莫爾的訊息不到半個鐘頭。補進去的那一行放回原來的位置，後面加註「據原件補錄」；附記裡添了一條，經辦人一欄寫的是沃爾特斯。

提交以前，她照習慣跑了一次 make test。最後幾行是：

```
[CSV]   16 vectors
[CROSS] 69000 comparisons with bit-by-bit rotation
[PROP]  2000 random cases x 3 properties
ALL PASS (0 failures)
```

兩千組性質檢查裡有一條：旋 n 位，再旋三十二減 n 位，回到原值，一個位元也不會少。

原件那半行是六個字。補錄的那一行是九個字。

作者時間一欄，她填的是十月八日下午三點五十五分，與會議同一天，時區 +0200；提交時間是十月二十五日，時區 +0100。`git log` 預設只印作者時間。在一串十月二十五日的提交中間，只有它印著十月八日。

範例報告在第二年九月開學前掛上課程網頁，給下一屆的一百四十二名修課學生，東方各州的分校在內。題記的出處排在頁腳，字號比正文小兩號。

（全文完）
