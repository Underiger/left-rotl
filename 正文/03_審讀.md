# 第三幕　審讀

二〇二六年十月二十二日，帝國大學後街，一家舊書店的樓梯底下，那間叫「老燈」的地下咖啡館還開著。

地窖的拱頂很低，磚縫裡往下滲水。一九六七年冬天以前，這裡印過一份叫《清晨》的油印小報，第七期印了四百份。那一期現在框在玻璃後面，掛在吧檯旁邊，底下一張護貝過的說明卡：本店歷史文物，請勿拍照。說明卡的旁邊是無線網路的實名登記辦法，一共九條。

諾伊曼和兩個別組的同學圍著一張木桌。桌上一台筆電，螢幕上是一段編譯器輸出：

```
$ riscv64-elf-gcc -march=rv32im_zbb -mabi=ilp32 -ffreestanding -O2 -S -o - c_baseline/rotl.c
rotl_ref:
	rol	a0,a0,a1
	ret
```

「一條。」諾伊曼說，「瑞士那邊的基金會早就批准了，叫 Zbb，語意跟我們的 rotl 一模一樣。GCC 加一個參數，自己就產生。我們偏要放在 custom-0，funct3、funct7 到今天還在等教師分配。等一個不知道哪一天下來的分配，就為了一條人家已經有的指令。」

一個戴眼鏡的女生唸他螢幕上的報告草稿，第二節第六款：「……建議本組 rotl 改採已批准之開放標準編碼，以利與既有工具鏈銜接，並與現行開放標準銜接。」

她說，這一句可以再斟酌，「銜接」用了兩次。

靠樓梯的位子上坐著一個穿灰外套的中年人，點了一杯咖啡，一直沒有喝。他的手機螢幕朝下擱在桌上。十點五十分，他去了一趟洗手間。十一點，他付了賬，上樓走進雨裡。

---

十一點四十分，諾伊曼被叫到電機館五樓。

研究室在走廊盡頭，不大，三面是鐵皮書架，大多是處理器手冊和舊的期末考卷。暖氣片是冷的，五樓的暖氣要等到十一月。桌燈罩著綠玻璃，光只照得到桌面。

桌上擺著四樣東西：一個紅色資料夾，封面印著系上教學文件審讀小組的章；一張 `riscv64-elf-objdump` 的列印，最上面一行用紅筆圈著：

```
84:  1eb5050b   .insn  4, 0x1eb5050b
```

一疊 CP3 報告草稿；一份列印出來的文件，標題是〈關於課程報告中開放標準引用的若干意見（送審稿）〉，末頁是會簽欄，組長、諾伊曼、埃克特、沃爾特斯，四格裡已經簽了三格。

福斯剛從圖書館回來，嗓子是啞的。她指了指對面的椅子，等諾伊曼坐下，打開紅色資料夾。

資料夾裡是審讀系統自動產生的預審報告，一共三頁。系上規定，各組報告上傳課程網頁以前須經預審。她一頁一頁地翻，語調和唸測資沒有兩樣。

「『左』，十七處。」翻一頁，「『開放標準』，一處。」又翻一頁，「『已批准』，一處。批准機關未註明。」

這一頁她在燈下多看了一會兒。

「批准機關未註明。」她說，「措辭很講究。『瑞士』兩個字寫出來，預審那一關就過不去。」

她把預審報告推了過去。

「莫爾下午送來的。另外附了一份人工審讀意見，兩條。第一條：題目名稱『循環左移』，報告中出現十七處；依《公民》課本第三課，帝國當前主要防左，請說明此『左』字之性質。第二條：第二節第六款建議改採境外標準，與作業規定第六節不符，請修改。」

諾伊曼沒有去碰那疊紙。

「組長，請您看另一本賬。」他說，「同樣是 a0、a1、a2，Zbb 的 rol 編出來是 0x60C59533，GCC 直接支援，objdump 印得出名字。我們的 rotl 是 0x1EC5850B，objdump 只會印 `.insn`。Ripes 不認得，Spike 要自己改。Zbb 另外有 I-type 的 rori，常數旋轉不用先放進暫存器。乙款是您定的，有序使用境外工具。窗戶已經有人開好了，我們偏要自己再鑿一個。」

「窗是瑞士人開的。」福斯說，「作業的題目是第十五號：設計一條自訂指令。用 Zbb，就是交別人的作業。」

她把 objdump 那張紙拉到燈下。

「工具是工具，標準是標準。Claude Code 寫的程式，每一行都在我們自己的機器上跑過。Zbb 的編碼，是人家的。」

「常數旋轉——」

「ChaCha20 每次旋轉省幾條？」

「一點九八。」諾伊曼說。

「不是兩條？」

「迴圈外面多了四條 li，十六、十二、八、七，還有一條 mv。R-type 的常數得先放進暫存器。」

「幾條？」

「五條。」

「執行幾次？」

「一次。」

「推算省六百四十條，實測省六百三十五條。」福斯說，「為了五條，你要去用人家的編碼。」

她把審讀意見翻回第一條。

「這一條，我來寫。」

她從草稿裡抽出第二節的測資表，用鉛筆點著 T04 那一行。

「rs1 等於 0x12345678，左旋三十一位，結果 0x091A2B3C，跟右旋一位一模一樣。左旋到頭，就是右旋。」她說，「這條指令往哪邊轉，要看 rs2，不看名字。」

她在預審報告的頁邊寫了一行字，是要加在 `spec/README.md` 第一行底下的註腳：本文件所稱「左」，係指位元編號遞增方向，與路線無關。

「第二條，」她說，「得你自己去改。」

她把送審稿翻到第三頁，用鉛筆點著唸：

「第二節第六款，你那一段刪掉。對照表照留，兩邊的 opcode、funct3、funct7、機器碼都列出來，人家的是人家的，我們的是我們的。表底下改成兩句：本組的 rotl 不是 Zbb 指令。報告與程式中一律使用 rotl 這個名稱，避免混淆。」

「您是要我親手——」

「我是要你在會簽欄裡簽字。」福斯說，「你去改，是技術說明；審讀小組去改，就是審讀意見了。這裡頭的區別，你比我清楚。」

諾伊曼過了一陣才開口。

「如果我不簽呢？」

「那就由審讀小組直接改稿，會簽欄少一格。」福斯說，「少的那一格，莫爾會看見，教師也會看見。」

她把送審稿合上。

「今天寫在第二節第六款，下個禮拜就寫在 CP4 的 datapath 上，到了期末，整條指令就是人家的了。funct7 先用 0001111，取題號十五；funct3 先用 000。分配下來，改 `rotl_isa.h` 兩行，`make test counts encode` 重跑一遍。C、組合語言、Python，都讀那一個檔案。」

「暫定的東西，要有一個地方管。」她說，「管的地方，只能有一個。」

「禮拜二晚上十一點五十九分以前，我要看到改過的第六款。」

諾伊曼拿起外套起身。走到門口時，福斯已經在看另一份東西了，是 RC5 金鑰排程的反組譯，頁邊夾著埃克特的一張便條。

---

電機館的屋簷底下積著水。諾伊曼沒有叫車，在台階上站了一會兒。

門口值夜的警衛開著手機，音量調得很低。晚間新聞正在唸教育部的通知：即日起在全帝國高校開展教學文件規範化整頓。接下來是帝國半導體總公司公布第三季度業績，自主指令集晶片出貨量同比增長百分之二十一。瑞士指令集基金會今日發表聲明——

警衛滑了一下螢幕，換到一個放舞曲的頻道。

---

第二天上午九點，那份〈關於課程報告中開放標準引用的若干意見〉由莫爾放進了小組的共用資料夾。

會簽欄裡，諾伊曼那一格已經打好了他的名字。範本把 Neumann 打成了 Neuman，少了一個 n。莫爾在列印稿上用原子筆補上了，補上的那個 n 比前後的字母都粗一點。

諾伊曼用指甲在那個 n 上刮了一下，然後簽了字。

那天下午，他把 `report/CP3.md` 第二節第六款改了。commit 訊息的標題只有兩個字：照擬。
