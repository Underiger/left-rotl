# 第四幕　境外晶片

二〇二六年十月二十四日凌晨，帝國大學圖書館前廣場。

學生是二十一日晚上開始坐下來的。教育部的整頓通知下來那天，系上的預審系統退回了四十一份報告。二十三日，系黨委發了〈關於暫停境外 AI 工具教學試點的通知〉，四個試點組停三個，留下第十五組，「以觀後效」。到第三天夜裡，廣場上坐了兩千多人，從圖書館的台階一直坐到噴水池邊上。

諾伊曼坐在台階最上面一級，背靠著圖書館的玻璃門。圖書館十二點閉館，門裡的無線網路還沒有關。他膝蓋上是一台 MacBook Air，晶片是 M5。這台電腦是他舅舅去年在阿姆斯特丹買的，進境的時候申報過，海關申報單還夾在包裝盒裡，品名欄寫的是「教學用計算器」。全組只有這一台是 ARM64。

電量剩百分之十八。系統問他要不要開啟低耗電模式，他按了好。

視訊通話一直開著。圖書館的網路要先經過校方的閘道，再轉進電機館，每句話到對面，要晚將近一秒。

凌晨兩點十分，`make verify` 跑完了。諾伊曼拿起手機。

---

電機館五樓，實驗室。

白板上畫著五級 pipeline：IF、ID、EX、MEM、WB，五個方格，一道箭頭從 MEM 繞回 EX，是 forwarding。旁邊用紅筆寫著三行：load-use 停一個 cycle；taken 分支與跳躍損失一或兩個 cycle；ROTL 與 sll 相同，在 EX 一個 cycle 完成。

福斯面前放著兩份東西。一份是 `pipeline_cycles.py` 的輸出，分支懲罰一和二，各三行。另一份是 `ic_crosscheck.py` 的輸出：不靠模擬器，只用 objdump 的反組譯加上 C 原始碼的迴圈次數推算動態指令數，六行，最右邊一欄全是勾。`rc5_setup` 那一行旁邊，埃克特用鉛筆註了一句：迴圈被編譯器轉過，進入前先跳到中間，第一條 lw 只執行七十七次。

「說吧。」

「ChaCha20，SHIFT 版一百八十四點一奈秒，ROR 版一百二十一點四，一點五二倍。」諾伊曼的聲音被網路壓得發扁，背後是一片人聲，「金鑰排程，一點三五倍。RC5 加密，一點三二倍。兩個版本的輸出都跟 RFC 8439、RC5 論文對得上。」

福斯在 pipeline 表的背面記下三個數，每個數只記到小數點後兩位。

「RC5 加密，」諾伊曼說，「RISC-V 的 IC 比是一點七三，實機只有一點三二，少了四成。我請求把實機的數字寫進 CP3 的結論：自訂旋轉指令使密碼學核心在真實 CPU 上加速一點三至一點五倍。不寫實機，人家會說 IC 比是我們自己的模擬器算出來的，自己說自己好。」

「這三個數是 ARM 的 ror，不是我們的 rotl。」福斯說，「CP3 只比較指令數，不比較 cycle 數，規定寫得很清楚。拿人家的晶片替我們的指令作證，這一句寫下去，CP3 就不是 CP3 了。」

她站起身，拿著手機走到白板前面。

「ARM 有右旋，沒有左旋。變數左旋，要先 neg，取一個負號，再 ror。在人家的晶片上，左旋就是負的右旋。我們的 rotl 一條，人家要兩條。這是第一個原因。」

她在白板上寫了一串字，用箭頭連起來：

```
eor → lsl/lsr → orr → add
eor → ror → add
```

「第二個原因。RC5 加密每一步：A 等於 A 異或 B，左旋 B 位，再加 S。每一步都要等上一步算出來的數。SHIFT 版四級，ROR 版三級，neg 可以跟 eor 同時做。四比三，一點三三。」她說，「M5 是亂序執行的，一個 cycle 能發好幾條，誰的資料先準備好，誰就先執行。分支，它可以先猜一個方向搶著做，猜錯了就把結果丟掉，不寫回暫存器，也不留下紀錄。等上一步的數，它猜不了。」

「ChaCha20 呢？」

「ChaCha20 一輪有四個 quarter round，互不相干，可以同時算。允許一部分 quarter round 先算起來，執行單元被填滿了，指令數就有用了。」她在白板角落寫了兩個數，「按相依鏈算，一點三三；按指令數算，一點六七。實測一點五一，夾在中間。這是從數字推出來的，沒有用效能計數器量過。」

「三個數寫進 experiments，照實寫，連前五次執行的範圍一起寫；RC5 為什麼只有一點三，寫兩個原因。CP3 的結論不寫實機，ror 的加速比不寫成 rotl 的加速比。」

線路那頭隔了一會兒，諾伊曼的聲音平了下來。

「還有一件事。」他說，「廣場上的人知道我們是試點組，現在只剩我們一組。他們有十四條，要我問你，試點組能不能聯署。我唸給您聽。」

他一條一條地唸。公開預審系統的關鍵詞表；停止調閱老燈群組的對話紀錄；四個試點組全部恢復；境外工具由修課學生自己選擇；被退回的四十一份報告重新審讀……

福斯在 pipeline 表背面記下條目編號，每一條只記一兩個字。

「……第十四條，系務會議設學生代表，由全系學生直接選舉，一人一票。」

線路裡是一段人聲。

「組長，我請求您授權我代表試點組聯署。」

福斯看了看自己記下的那一列字。

「前面十三條是要價，」她說，「第十四條是要這個系。你把試點組的名字簽下去，系黨委擺在哪裡？試點擺在哪裡？」

「組長——」

「剝開來看，就是一句話：拿試點組當擋箭牌。其他的都是包裝紙。」

線路那頭隔了一會兒。

「霍恩書記等的就是廣場散不了。」諾伊曼說，「散不了，第十五組也停，到時候他站在廢墟上說他是對的。組長，您是想把試點辦下去，還是想替霍恩書記收場？」

「這種話，留著寫期末心得。」福斯說。

她拿著手機走到窗邊，充電線拉直了，繃在桌角上。窗外是圖書館的方向，廣場上的燈一盞連著一盞，看不清人。

「這場風波遲早要來。」她說，「瑞士的開放標準、美國的晶片、境外的 AI，這是大氣候。系上開了一個月試點，這是小氣候。寫不出作業的時候要 AI，有了 AI 要選標準，選了標準，就要選系務會議的代表。這十四條不是一個晚上寫出來的，是這一個月一條一條長出來的。」

她頓了頓。

「長出來的東西，要收。」

電話那頭沒有聲音。

「我只說一遍，你一條一條記。試點組的對話紀錄，我公開：每一份報告第六節寫清楚，哪一段是 Claude Code 寫的，哪一段是人改的。預審的關鍵詞表，我去系務會議上要，禮拜一給答覆。四個試點組恢復，我寫書面意見給系主任。」

諾伊曼在那頭複述了一遍。網路讓他的每句話都晚一點到。

「有三樣不給。聯署不簽，學生代表不提，系黨委的通知不碰。」

「他們不會接受。」

「那是他們的事。你告訴他們，想交作業，回宿舍去。對話紀錄照公開，書面意見照寫。退一步可以，退兩步就沒有試點了。他們要是連系務會議也要，保衛處早上八點清場。」

她回頭看了一眼桌上的 pipeline 表。

「必要的時候，試點停一學期，換這個系三年不出事。這筆賬我算過了。你原話轉告他們。」

線路裡有很長一段只有人聲。然後，隔著一段距離，傳來一個陌生的聲音，女的，很年輕，說了一句很短的話。

諾伊曼重新拿起手機。

「系學會的科赫說，她要回去問同學。天亮以前給答覆。」

「好。天亮以前。」

---

三點十分，班上的群組裡貼出一則聲明，署名是第十五組：試點組全體同學堅決擁護系黨委的一切決定。

第十五組的四個人，誰也沒有發過這則聲明。那時候系黨委也還什麼決定都沒有做。福斯把聲明截了圖，存進資料夾，按收到的時間排序。

---

三點四十分，實驗室的門開了。

霍恩書記走進來，穿一件深色長大衣，肩上沒有一滴雨，手裡提著一個皮面公事包，銅扣擦得很亮。他身後跟著兩個人：莫爾，和保衛處的一位副處長。

「福斯同學，」霍恩微微點頭，「廣場上的人佔了圖書館的台階，每拖一個小時，就多一個系響應。這不是一般的請願，是有計劃的，是一場動亂。」

他打開公事包，取出兩份東西。第一份是系網首頁的頁面預覽，早上八點發布，社論標題用的是最大號黑體字：〈必須旗幟鮮明地反對動亂〉。第二份是一張表態書，抬頭印著「帝國青年團電機系第十五組支部」，簽名欄空著。

「支部書記簽個字。」他說，「系網八點發社論，表態書一起發。保衛處的同志八點清場。」

福斯看了看表態書，沒有伸手。

「如果我不簽呢？」

「那就說明支部書記已經無力維持班上的秩序。」霍恩說，「系上的同志都會很擔心。試點，也就沒有辦下去的必要了。」

莫爾從自己的資料夾裡抽出一份列印稿，放在表態書旁邊，是 CP3 評分意見的草稿：〈關於第十五組 CP3 報告效能結論的意見〉。

「另外，」他說，「依你們自己的 pipeline 模型，自訂指令版的 CPI，ChaCha20 從一點零四二升到一點零六二，RC5 加密從一點一零六升到一點一八三。改了以後，每條指令平均要花更多的週期。改革改出了退步。我的意見，CP3 的結論改成『效果待商榷』，experiments 這個目錄刪掉。」

「總週期數呢？」

莫爾低頭看了一眼底下那張表。「ChaCha20，一千九百九十九，降到一千三百六十四。」

「停頓呢？」

「兩個版本都是八十個 cycle。」

「停頓一個也沒多。」福斯說，「CPI 升了，是因為指令少了，同樣八十個停頓，攤到更少的指令頭上。一千九百一十九條攤八十個，一千二百八十四條也攤八十個，你算一算哪一邊攤得多。只看 CPI，不看總數，這不叫實事求是。」

莫爾換了一個方向。他做了三年助教，知道一條路走不通的時候該退到哪裡。

「金鑰排程旋轉一百五十六次，三個核心裡最多；動態指令只少了百分之十八點九，三個裡最少。改了半天，改不到要害。」

「旋轉多，不等於旋轉佔得多。金鑰排程的指令，四分之三花在載入、儲存、算索引上。只有改了的那一部分會變快。」福斯說，「Amdahl 定律，課本第一章。」

「拿美國晶片的數字，寫帝國大學的報告，合適嗎？」

福斯從桌子另一頭拿過 CP3 的報告草稿，翻到第三節第五款〈限制〉。第二條是她上個禮拜寫的：

> 超出本次範圍的初步估計（5 級 pipeline 模型、ARM64 實機量測）放在 experiments/，不屬於 CP3 的繳交內容。

「你要刪的那個目錄，本來就不在繳交範圍裡。」她說，「至於美國晶片，寫的是『旁證』。旁證的意思，就是不拿它當證據。」

她又從桌子另一頭拿過一個牛皮紙資料夾，放在表態書旁邊。封面蓋著系主任室的章，標題是〈關於預審系統關鍵詞表修改紀錄的說明〉。

莫爾低頭看了一眼。霍恩提著公事包的那隻手，把銅扣扣上了。

「十月二十日晚上十一點零四分，預審系統的關鍵詞表多了三個詞：試點、開放、境外。修改帳號是課程助教室。」福斯說，「二十一日，四十一份報告被退回，三十八份是試點組和用了 AI 的組。二十三日，系黨委發暫停通知，理由是『試點組報告預審退回率異常』。」

她抬眼看了看保衛處的副處長。

「修改紀錄，資訊中心那邊有備份。兩點鐘，我已經轉給系主任和教務處了。」

保衛處的副處長把目光移開了。

「沒有我們，你們收不了場。」霍恩說。

「廣場的事，不用書記操心了。」

霍恩看了她一會兒，把表態書收回公事包。社論的頁面預覽還留在桌上。福斯拿起來，從第一行看到最後一行。

「社論照發。」她說，「署名改成本系評論員。」

霍恩走了，莫爾跟在後面。保衛處的副處長還站在原地。

「八點那件事，」他說，「要不要撤？」

「不撤。」福斯說，「時間、地點、人數，都不動。」

副處長站了幾秒鐘，出去了。

---

圖書館前廣場，凌晨四點二十分。

霧落在臉上才知道是雨。台階上擠滿了人，一直擠到噴水池邊上。有人舉著用床單寫的標語，字被雨泡得往下淌，已經認不出寫的是什麼。更多的人什麼也沒舉，肩膀挨著肩膀坐著。

科赫站在台階中間，用一個手持擴音器講了很久。諾伊曼坐在最上面一級，筆電抱在懷裡，螢幕已經黑了。講完了，科赫回頭看了他一眼，把擴音器遞過來。

擴音器的把手被人握得溫熱。

諾伊曼站起來，看著底下的人。大多是一、二年級的，外套裡面還穿著系服，嘴唇凍得發紫。

他舉起擴音器。擴音器先嘯叫了一陣，他等它停下來。

「試點組的對話紀錄，會公開。」他說，「書面意見，組長會寫。關鍵詞表的事，禮拜一給答覆。你們在這裡坐了三天，身體會垮的。期中考還沒考。回宿舍去吧，天亮以前回去。」

底下有人喊了一句什麼，很多人跟著喊。科赫湊到他耳邊說，他們在問：那選舉呢？

諾伊曼沒有回答，把擴音器放了下來。

台階底下，保衛處的一個工作人員舉起手機，閃光燈亮了一下，又亮了一下。

---

凌晨五點四十分，諾伊曼又打來了。他已經回到宿舍，筆電插上了電。

「組長，第二輪跑完了。」他的聲音比剛才急，「數字少了一半。ChaCha20，SHIFT 九十六點零，ROR 六十三點四。」

沃爾特斯是五點半到的，來拿校對稿。她抬起頭。

「比值呢？」福斯說。

那頭停了幾秒鐘。「一點五一。」

「那就沒事。」

「可是奈秒——」

「奈秒跟著核心走。效能核心、節能核心，插電、不插電，低耗電模式開不開，絕對時間都不一樣。你在台階上開著低耗電模式跑，在宿舍插著電跑，奈秒當然不一樣。」福斯說，「兩個版本在同一次執行裡依序量，處在同一個狀態下，比值是穩的。你用 `/usr/bin/time -l` 再跑一次，看 swaps。」

過了一分鐘，諾伊曼回來了：「零。」

「工作資料只有幾百個位元組，全在快取裡。」福斯說，「寫進去：請看加速比，不要看奈秒的絕對值。」

五點五十分，保衛處的副處長傳來一份通知稿，兩頁，請支部書記提意見。

福斯把第二頁的「清場」改成「勸離」，把「必要時採取強制措施」整行劃掉，在旁邊寫：不得進入圖書館台階範圍；不得攝影。

「八點清場，是說給他們聽的。」她對沃爾特斯說，「勸離的人數，由保衛處統一口徑，四十八小時內不對外公布。」

諾伊曼的稿子是六點零五分傳來的。福斯從頭看到尾，在最後一段後面加了一節，標題是〈尚未驗證的部分〉，第一行寫：

> Clock period：假設 ROTL 不拉長 clock period，待 CP4 畫出 datapath 後確認。

她把稿子交給沃爾特斯。

「CP3 第三節第五款，加一句『見 experiments/』，指過去就好。」

沃爾特斯把改過的稿子拿到隔壁的印表機。印表機在第三頁卡了紙，她把紙扯出來，重新裝上一疊，從頭印了一遍。

七點半，科赫在廣場上宣布，接受對話紀錄公開和書面意見兩條，同學分批返回宿舍。台階東側有三十幾個人沒有走。保衛處八點到了，按通知稿勸離，沒有攝影。
