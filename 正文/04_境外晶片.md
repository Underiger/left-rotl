# 第四幕　境外晶片

二〇二六年十月二十四日凌晨，帝國大學第三宿舍四樓。

宿舍凌晨一點統一斷電。諾伊曼的書桌上只點著一盞夾在行動電源上的小燈，燈罩轉向牆壁，是室友要求的。

桌上一台 MacBook Air，晶片是 M5。這台電腦是他舅舅去年在阿姆斯特丹買的，進境的時候申報過，海關申報單還夾在包裝盒裡，品名欄寫的是「教學用計算器」。全組只有這一台是 ARM64。

視訊通話一直開著。宿舍的網路要先經過校方的閘道，再轉進電機館，每句話到對面，要晚將近一秒。

凌晨兩點十分，`make verify` 跑完了。諾伊曼拿起手機。

---

電機館五樓，實驗室。

白板上畫著五級 pipeline：IF、ID、EX、MEM、WB，五個方格，一道箭頭從 MEM 繞回 EX，是 forwarding。旁邊用紅筆寫著三行：load-use 停一個 cycle；taken 分支與跳躍損失一或兩個 cycle；ROTL 與 sll 相同，在 EX 一個 cycle 完成。

福斯面前放著兩份東西。一份是 `pipeline_cycles.py` 的輸出，分支懲罰一和二，各三行。另一份是 `ic_crosscheck.py` 的輸出：不靠模擬器，只用 objdump 的反組譯加上 C 原始碼的迴圈次數推算動態指令數，六行，最右邊一欄全是勾。`rc5_setup` 那一行旁邊，埃克特用鉛筆註了一句：迴圈被編譯器轉過，進入前先跳到中間，第一條 lw 只執行七十七次。

「說吧。」

「ChaCha20，SHIFT 版一百八十四點一奈秒，ROR 版一百二十一點四，一點五二倍。」諾伊曼的聲音被網路壓得發扁，「金鑰排程，一點三五倍。RC5 加密，一點三二倍。兩個版本的輸出都跟 RFC 8439、RC5 論文對得上。」

福斯在 pipeline 表的背面記下三個數，每個數只記到小數點後兩位。

「RC5 加密，」諾伊曼說，「RISC-V 的 IC 比是一點七三，實機只有一點三二，少了四成。」他停了一下，「組長，我請求把實機的數字寫進 CP3 的結論：自訂旋轉指令使密碼學核心在真實 CPU 上加速一點三至一點五倍。不寫實機，人家會說 IC 比是我們自己的模擬器算出來的，自己說自己好。」

福斯看了看自己記下的那一列數。

「這三個數是 ARM 的 ror，不是我們的 rotl。」她說，「你把『自訂指令加速一點五倍』這一句寫下去，CP3 擺在哪裡？作業規定擺在哪裡？CP3 只比較指令數，不比較 cycle 數，規定寫得很清楚。」

「組長——」

「剝開來看，就是一句話：拿人家的晶片，替我們的指令作證。其他的都是包裝紙。」

線路那頭隔了一會兒，諾伊曼的聲音平了下來。

「不寫，莫爾助教會說 experiments 這個目錄是多餘的。四十幾個小時跑出來的東西，到頭來只能放在範圍以外。」

福斯站起身，拿著手機走到白板前面。

「ARM 有右旋，沒有左旋。」她說，「變數左旋，要先 neg，取一個負號，再 ror。在人家的晶片上，左旋就是負的右旋。我們的 rotl 一條，人家要兩條。這是第一個原因。」

她在白板上寫了一串字，用箭頭連起來：

```
eor → lsl/lsr → orr → add
eor → ror → add
```

「第二個原因。RC5 加密每一步：A 等於 A 異或 B，左旋 B 位，再加 S。每一步都要等上一步算出來的數。SHIFT 版四級，ROR 版三級，neg 可以跟 eor 同時做。四比三，一點三三。」她說，「M5 是亂序執行的，一個 cycle 能發好幾條，誰的資料先準備好，誰就先執行。可是資料沒準備好的，它也只能等。分支，它可以先猜一個方向搶著做，猜錯了就把結果丟掉，不寫回暫存器，也不留下紀錄。等上一步的數，它猜不了。」

「ChaCha20 呢？」

「ChaCha20 一輪有四個 quarter round，互不相干，可以同時算。執行單元被填滿了，指令數就有用了。」她在白板角落寫了兩個數，「按相依鏈算，一點三三；按指令數算，一點六七。實測一點五一，夾在中間。這是從數字推出來的，沒有用效能計數器量過。寫的時候，這一句要寫上。」

線路那頭沒有聲音。

「我只說一遍，你一條一條記。三個數寫進 experiments，照實寫，連前五次執行的範圍一起寫。RC5 為什麼只有一點三，寫兩個原因。結論寫：三個核心在真實硬體上都變快了，沒有一個變慢。」

諾伊曼在那頭複述了一遍。網路讓他的每句話都晚一點到。

「有三樣不寫。CP3 的結論不寫實機；ror 的加速比，不寫成 rotl 的加速比；奈秒的絕對值，不拿來比。」

「莫爾助教不會接受。」

「那是他的事。他要扣分，扣的是 CP3 的分，experiments 不在 CP3 裡面。」

她回頭看了一眼桌上的 pipeline 表。

「你要是非把實機寫進結論不可，CP3 就整份重寫，你一個人寫。這筆賬我算過了。」

線路裡有很長一段只有筆電風扇的聲音。然後，隔著一段距離，傳來另一個聲音，低沉，含糊，是諾伊曼的室友翻了個身，說了一句很短的夢話。

諾伊曼重新拿起手機。

「我照您說的寫。天亮以前給您看稿。」

「好。天亮以前。」

---

三點四十分，實驗室的門開了。

莫爾走進來，手裡提著一個帆布公事包，肩上沒有一滴雨。他是博士班三年級，座位就在實驗室的另一頭，這個禮拜在改 CP2。他打開公事包，取出一份列印稿，是 CP3 評分意見的草稿，標題用的是最大號的黑體字：〈關於第十五組 CP3 報告效能結論的意見〉。

「福斯同學，」他說，「依你們自己的 pipeline 模型，自訂指令版的 CPI，ChaCha20 從一點零四二升到一點零六二，RC5 加密從一點一零六升到一點一八三。改了以後，每條指令平均要花更多的週期。」他把那張紙放在桌上，正壓在 pipeline 表上面，「我的意見，CP3 的結論改成『效果待商榷』，experiments 這個目錄刪掉。只要組長同意，我早上就送教師。」

福斯看了看評分意見，沒有伸手。

「總週期數呢？」

莫爾低頭看了一眼底下那張表。「ChaCha20，一千九百九十九，降到一千三百六十四。」

「停頓呢？」

「兩個版本都是八十個 cycle。」

「停頓一個也沒多。」福斯說，「CPI 升了，是因為指令少了，同樣八十個停頓，攤到更少的指令頭上。一千九百一十九條攤八十個，一千二百八十四條也攤八十個，你算一算哪一邊攤得多。」

莫爾換了一個方向。他做了三年助教，知道一條路走不通的時候該退到哪裡。

「就算總週期降了，也要看降在哪裡。」他說，「金鑰排程旋轉一百五十六次，三個核心裡最多；動態指令只少了百分之十八點九，三個裡最少。改了半天，改不到要害。」

「旋轉多，不等於旋轉佔得多。」福斯說，「金鑰排程的指令，四分之三花在載入、儲存、算索引上。只有改了的那一部分會變快。Amdahl 定律，課本第一章。」

「還有一件事。」莫爾說，「拿美國晶片的數字，寫帝國大學的報告，合適嗎？」

福斯從桌子另一頭拿過 CP3 的報告草稿，翻到第三節第五款〈限制〉，放在評分意見旁邊。第二條是她上個禮拜寫的：

> 超出本次範圍的初步估計（5 級 pipeline 模型、ARM64 實機量測）放在 experiments/，不屬於 CP3 的繳交內容。

莫爾低頭看了一眼。他提著公事包的那隻手，把扣環扣上了。

「你要刪的那個目錄，本來就不在繳交範圍裡。」福斯說，「至於美國晶片，第三節寫的是『旁證』。旁證的意思，就是不拿它當證據。」

「那它留在倉庫裡做什麼？」

「留著。」福斯說，「CP4 要畫 datapath，用得著。檔案、數字、前提，都不動。」

莫爾站了幾秒鐘，把評分意見收回公事包，回到實驗室的另一頭去了。

---

凌晨五點四十分，諾伊曼又打來了。

「組長，第二輪跑完了。」他的聲音比剛才急，「數字少了一半。ChaCha20，SHIFT 九十六點零，ROR 六十三點四。」

沃爾特斯是五點半到的，來拿校對稿。她抬起頭。

「比值呢？」福斯說。

那頭停了幾秒鐘。「一點五一。」

「那就沒事。」

「可是奈秒——」

「奈秒跟著核心走。效能核心、節能核心，插電、不插電，絕對時間都不一樣。」福斯說，「兩個版本在同一次執行裡依序量，處在同一個狀態下，比值是穩的。你用 `/usr/bin/time -l` 再跑一次，看 swaps。」

過了一分鐘，諾伊曼回來了：「零。」

「工作資料只有幾百個位元組，全在快取裡。」福斯說，「寫進去：請看加速比，不要看奈秒的絕對值。」

諾伊曼的稿子是六點零五分傳來的。福斯從頭看到尾，在最後一段後面加了一節，標題是〈尚未驗證的部分〉，第一行寫：

> Clock period：假設 ROTL 不拉長 clock period，待 CP4 畫出 datapath 後確認。

她把稿子交給沃爾特斯。

「整份重寫，是說給他聽的。」她說，「CP3 第三節第五款，加一句『見 experiments/』，指過去就好。」

沃爾特斯把改過的稿子拿到隔壁的印表機。印表機在第三頁卡了紙，她把紙扯出來，重新裝上一疊，從頭印了一遍。
