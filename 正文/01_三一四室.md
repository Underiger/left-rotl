# 第一幕　三一四室

二〇二六年十月八日的小組討論，原定下午兩點開始，因為電機館三一四室的門禁沒有按時打開，推遲到兩點四十分。

總務處上個月發了通知：自十月一日起，電機館各討論室憑預約開門，預約時段結束十五分鐘後斷電。三一四室這一次預約的是兩點到四點。預約系統的時段欄用的是十二小時制，把「2:00」登記成了凌晨兩點，門禁到兩點三十五分才由工友拿鑰匙打開。暖氣按規定十月十五日才供，與會的人進門時都沒有脫外套。

長桌上，每個座位前擺著一份列印的材料，用長尾夾夾著，封面手寫編號，一到五。系上的列印額度每人每學期三百頁，新紙要省，大半印在上學期期末考卷的背面，翻過來還能看見一道 Booth 乘法的計算題，紅筆批了零分。印表機的碳粉匣快用完了，十六進位的數字淡得發灰，有幾頁是埃克特拿鉛筆逐個描過的。

材料一共三份。作業規定第六節〈題目語意規格〉，十二頁，第十五號題目在第七頁，一共四行。C 參考實作初稿，十四行，連註解在內。CP1 報告初稿，十一頁，第六節〈AI 使用說明〉只有一行：工具，Claude Code。

九月開學的第一次系務會議上，系主任朗格提了一個方案：境外 AI 工具在教學中「有序開放」，先在《計算機組織》挑四個組試點，不搞全系一刀切，成熟一個，推廣一個。系黨委書記霍恩在會簽欄裡寫了四個字：原則同意。第十五組是四個試點組之一。系上的人都知道，霍恩書記寫「原則同意」的時候，重點在前兩個字。

長桌左手邊是諾伊曼。他面前除了材料，還開著一台筆電，外殼貼滿了貼紙，終端機的游標一直在閃。靠牆的小桌後面，沃爾特斯在做記錄。她用筆電打字，手邊另放一本橫線筆記本，兩樣都用。右手邊坐著助教莫爾，他是霍恩書記指導的博士生；按系上的規定，試點組的每一次正式討論，都須有助教列席。埃克特坐在長桌最末端，靠窗，外套拉鍊拉到最上面。

福斯坐在主位。她是組長，也是班上的青年團支部書記。她從進門起就在看那份報告初稿，手裡一枝鉛筆，隔幾頁在頁邊點一下。

會已經開了一個鐘頭。

莫爾面前除了會議材料，還擺著一個藍色資料夾，裡面是他自己印的作業規定全文，紙頁間夾著七八張便利貼。他說話的時候不大看人，看資料夾。

「第六節第四款，第七頁。」他翻到一張便利貼，「rs2 低 5 位元為移位量。」他把資料夾轉過去，推到桌子中央，「移位量是零到三十一。你們的測資裡有三十二、三十三，還有負一、負二十八。我想請你們說明一下，負二十八和第七頁是什麼關係。」

諾伊曼把筆電轉了個方向：「按我們的測試，負二十八取低五位以後——」

「我問的不是測試。」

諾伊曼手裡繞著一條充電線，等莫爾說完，才把線放下。

「莫爾助教說到第七頁，我倒認為問題正出在第七頁。」他說，「第七頁的公式只有一行：rs1 左移 n，或上 rs1 右移三十二減 n。初稿多寫了一個 if，n 等於零的時候直接回傳。我在 Mac 上跑過，不寫那個 if，n 等於零照樣輸出 0x12345678，硬體本來就只看低五位。我的意見兩條：測資再加，加到一千組；那個 if 拿掉。」

「第七頁還有半行。」莫爾把資料夾翻過來，「n = 0 時 rd = rs1。這半行，你要拿掉？」

「那半行講的是結果，不是寫法。結果，硬體已經算對了。」

莫爾把資料夾合上。「諾伊曼同學，你這兩條，是在替作業規定出主意，還是在替你的 AI 出主意？」

「我在替一份兩個禮拜以後還交得出 CP2 的報告出主意。」

「第三節，第二頁。」

福斯沒有抬頭。

「費利克斯，第三節第二頁，交叉驗證。一千個輸入值；rs2 從零走到六十三，六十四種，另外還有五個接近二的三十二次方的值。分項加起來是六十九種，合計欄寫的是六萬四千次。」她把報告轉過去，又把諾伊曼的筆電往自己這邊扳了一點。終端機最後幾行印著：

```
[CROSS] 69000 comparisons with bit-by-bit rotation
```

「程式自己印出來的是六萬九千次，差了五千次。」她說，「是你們的工具乘錯了，還是有人覺得五千這個數不好看？」

諾伊曼接過報告，手指順著那一段往下點，點到一半停住了。

「分項是對的。總數錯了。」他說，「初稿是 Claude Code 寫的。那五個大的 rs2，它沒乘進去。」

「那就是有人沒有核對。」福斯把鉛筆擱下，「散會以前，把產生這一段的對話紀錄存檔。」

莫爾低頭在便利貼上記了一筆。

「連乘法都會乘錯。」他說，「霍恩書記在系務會議上講過，境外工具寫出來的東西，根子上就不乾淨。今天替你寫迴圈，明天替你寫報告，後天替你想。」

「六萬四千是乘錯了。乘錯的是工具，沒核對的是人。」福斯說，「程式乾不乾淨，看 UBSan，不看出身。」

她頓了一下。

「我不管程式是人寫的還是 Claude 寫的。能過六萬九千次比對，就是好程式。」

莫爾又在便利貼上記了一筆，記完才發覺不對，把那張便利貼撕下來，揉成一團。

「剛才說到哪裡？」

「說到第七頁。」莫爾說。

「好，那就說第七頁。」

福斯把報告翻回第二節的測資表。

「T05，rs2 等於三十二，二進位是一後面五個零，取低五位，n 等於零，結果等於 rs1。T06，三十三，n 等於一。T07，負一，十六進位八個 F，低五位全是一，n 等於三十一，等於右旋一位。T08，負二十八，0xFFFFFFE4，低五位是四。」

她一行一行點過去，點一行，說一個數。

「第七頁寫的是『低 5 位元』。負數也有低五位元。高二十七位，第七頁一個字也沒有提。沒有提，就是不問。」她看著莫爾，「這幾組不是在測規格沒寫的東西，是在測寫錯的程式。有人拿 % 32 取移位量，負二十八取出來還是負二十八；有人忘了只取低五位；有人把 rs1 存成 int，右移的時候左邊補一；有人把繞回的方向寫反。T07、T08、T11、T12，抓的就是這幾種人。」

「莫爾助教，這筆賬我第一次修程式設計就算過，那時候扣的是我的分。你要守第七頁，我不反對。這幾組拿掉，你去跟教師說，期末的隱藏測資不考負數。」

末席的埃克特把兩手從外套口袋裡拿了出來，擱在桌上。

福斯轉向左邊。

「費利克斯，你說那個 if 拿掉。」

「硬體只看低五位，」諾伊曼說，「三十二就是零。」

「C11，第六點五點七節，第三段。」福斯說，「右運算元大於等於左運算元的寬度，行為未定義。rs1 是三十二位元，n 等於零的時候，你算的是 rs1 右移三十二。」

「可是跑出來是對的。」

「你那台 Mac 跑出來是對的，是因為 arm64 的移位器只看低五位，剛好把三十二當成零。」福斯說，「未定義的意思，不是會算錯，是標準對結果沒有任何保證。這一次剛好，換一個編譯器、換一個最佳化等級，它可以給你任何一個數，也可以假設這件事不會發生，把你整段程式刪掉。下個禮拜，這份程式要拿去給 RISC-V 的編譯器編。」

她朝筆電抬了抬下巴。「make ub-demo。」

諾伊曼敲了幾下鍵盤。終端機往上滾了幾行：

```
rotl_naive(0x12345678, 4) = 0x23456781
c_baseline/ub_demo.c:16:30: runtime error: shift exponent 32 is too large for 32-bit type 'uint32_t'
make: *** [ub-demo] Abort trap: 6
```

「報錯了。」莫爾說。

「echo 一下。」

諾伊曼打了 `echo $?`。螢幕上出來一個零。

「報錯是對的。」福斯說，「Makefile 那一行前面有一個減號，make 不理它。這一條是反例，就是要它報錯。不加 UBSan，這個錯誤根本看不出來。」她在報告第四節的空白處寫了一行字，「寫進第四節，遭遇的問題。」

諾伊曼沒有再說話。

「剛好算對，」福斯說，「不等於算對。」

牆邊，沃爾特斯的手指停在鍵盤上。

「這句不用記。」福斯說。

沃爾特斯沒有按刪除鍵。她把打了一半的那一行選起來，前後各加了兩個波浪號。存檔以後，那半行字中間多了一道橫線。

「還有一件事，順便說一下。」福斯說，「系上現在的毛病，右的有，左的也有。根子扎得深的，是左的。作業規定背得出來，程式跑不出來；境外工具一律不准碰，學長的舊作業一屆一屆往下傳，傳了二十年，沒有人說那是精神污染。」

莫爾的筆停了。

福斯轉過頭，看了看長桌兩側。

「你們一個要把第七頁逐字照抄，一個要把 if 交給硬體。照抄的，連負數都不敢測；交給硬體的，連標準都不看。想一個晚上讓 AI 把整份報告寫完，這也是毛病。主要防左，右也要反。這兩句是連在一起說的，不要只記前半句。」

她轉過頭。「紀要。」

沃爾特斯另起了一段。

「一，本組一切工作以通過全部測資為中心。二，在此前提下：甲，嚴守作業規定，第五節、第六節照辦；乙，開放使用境外工具，提高效率。」

她說得不快，每一條中間留出沃爾特斯打字的時間。

「三，參考實作保留 n 等於零的分支。測資十六組照留，負數照留。交叉比對次數以程式輸出為準，六萬九千次。四，凡由 Claude Code 產生的程式和文字，每一行都要在本機跑過，跑過的寫進第六節。只問跑沒跑過、過沒過，不問是人寫的還是機器寫的。姓人還是姓機，這個問題，會上不爭論，會後也不爭論。」

「步子邁多大？」諾伊曼問。

「摸著位元過河。改一行，跑一次 make test；全綠了，再改下一行。」

諾伊曼低頭打了下來。

「五，make ub-demo 的報錯，寫進第四節。」

「六，Git 規則照第五節第一款：各人在自己的 dev 分支開發，不直接推送 main。PR 由我審，tag 由我打。」福斯說完這一條，看了看長桌兩側，「第二條的甲款和乙款，誰要去動甲款，不管坐在哪一邊，不管寫過多少行、讀過多少論文，先 revert 他。這句也不用記。」

莫爾把資料夾合上了。

「組長的意思，我是不是可以歸納一下，」他說，「以測資為綱？」

福斯看了他一眼。

「綱就不必了。」她說，「叫一個中心，兩個基本點。」她對沃爾特斯說，「標題就這麼寫。散會。」

---

走廊很長，天花板很高，腳步聲撞在水磨石地上。諾伊曼和沃爾特斯走到樓梯口，誰也沒有先開口。

「她說的是每一行都要在本機跑過。」沃爾特斯說。

「我聽見了。」

「跑過了，也是用。」

諾伊曼下了兩級台階，停住了。

「甲款寫在紀要裡，」他說，「乙款寫在提示詞裡。提示詞是可以改的。」

沃爾特斯把筆電抱在胸前，沒有回答。

---

三一四室的電是四點十五分斷的。沃爾特斯把紀要打好拿進來的時候，日光燈已經暗了，福斯就著筆電螢幕的光看稿。

她改了三處：第一條「通過全部測資」，刪去「全部」兩字；第二條乙款「開放使用」，改成「有序使用」；第四條「每一行都要在本機跑過」後面，加上「跑一行，記一行」。討論紀錄裡劃了橫線的那半行，她整行刪掉了。

「全部那兩個字，」沃爾特斯問，「為什麼刪？」

「make ub-demo 那一條，」福斯說，「是要它不通過的。」

「開放改成有序呢？」

「霍恩書記看得懂開放，」福斯說，「看不懂有序。」

她又往下看了一遍。

「出席人員的排序，埃克特放第三位。」

「莫爾助教原來是第三位。」

「放第五。列席的放最後。」

產生第三節第二頁的那段對話紀錄，四點十二分存了檔，檔名是 `cp1_draft_1007.txt`。福斯在報告初稿最後一頁的空白處寫：第二節交叉比對次數，以程式輸出為準重算；對話紀錄存檔，另行處理。

紀要提交了兩次。第一次是沃爾特斯在會上打的速記稿，第二次是組長改過的定稿，commit 訊息的標題只有兩個字：定稿。紀要另印了五份，編號一至五，與會議材料的編號一一對應，印在期末考卷的背面。第五份送系辦，簽收欄裡是莫爾本人的簽名。
