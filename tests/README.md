# 附件二　測資

- 對應：CP1–CP3；正文第一幕
- 規定：至少 10 組，含 3 組以上邊界值（作業規定第六節）

[`rotl_vectors.csv`](rotl_vectors.csv)：16 組，欄位為 `id, rs1, rs2, expected, category, note`。依紀要第三條，十六組照留，負數照留。

| 類別 | 數量 | 涵蓋 |
|---|---:|---|
| `spec` | 2 | 作業規定 6.4 的公告測資（第三組 `n = 0` 歸在 boundary） |
| `boundary` | 10 | `n = 0`、`n = 31`、`rs2 = 32／33`、`rs2` 為負值、全 0、全 1、最高位繞回、最低位旋到最高位 |
| `general` | 4 | 旋轉 16 位（交換半字）、旋轉 4 位、一般值、交錯位元樣式 |

負數測資的用途：第七頁只規定 rs2 的低 5 位元，高 27 位元不問。T07（`rs2 = −1`，低 5 位元為 31）、T08（`rs2 = −28`，低 5 位元為 4）用來檢出以 `% 32` 取移位量、或以有號數處理 rs2 的寫法；T11、T12 檢出右移誤用算術右移、繞回方向寫反的寫法。

同一份 CSV 由三處讀取，口徑一致：

- `c_baseline/test_rotl.c`（主機 C 測試）
- `tools/test_rotl_isa.py`（黃金模型測試）
- `tools/test_rv32.py`、`tools/measure.py`（在 RV32 模擬器上執行）
